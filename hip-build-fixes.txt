# HIP Build Fixes Summary

## Changes Made

### 1. tests/CMakeLists.txt
- Disabled `--coverage` flag for HIP builds (lines 33-40)
- Removed `gcov` library linking for HIP builds (lines 94-97)

### 2. CMakeLists.txt
- Disabled coverage instrumentation for HIP builds (lines 164-167)

### 3. include/cudawrappers/cufft.hpp
Added HIP compatibility layer after header includes:
- Type aliases: `cudaDataType_t`, `cufftResult`, `cufftResult_t`, `cufftHandle`
- Macro definitions: `CUFFT_*` constants → `HIPFFT_*`
- Function macros: `cufft*` → `hipfft*`
- Data type macros: `CUDA_*` → `HIPFFT_*`

### 4. include/cudawrappers/cu.hpp
Added HIP-specific conversion operator to `Stream` class:
```cpp
#if defined(__HIP__)
  inline operator hipStream_t() const { return static_cast<hipStream_t>(_obj); }
#endif
```

### 5. include/cudawrappers/cu_backend.hpp
Added `#if !defined(__HIP__)` guards around CUDA header includes (lines 399, 691)

## Root Causes Fixed

1. **Coverage instrumentation failure**: HIP toolchain doesn't support LLVM coverage runtime
2. **Type mismatches**: CUDA types (`cufftResult_t`, `cudaDataType_t`, etc.) don't exist in HIP
3. **Function name mismatches**: `cufft*` functions are `hipfft*` in HIP
4. **Stream conversion**: `cu::Stream` needs explicit conversion to `hipStream_t` for HIP builds
